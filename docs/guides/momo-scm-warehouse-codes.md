## 適用 API 對照

### 1. 查詢使用

- **《SCM_入庫單列印API》**
  - 入庫通知查詢
  - 刪單查詢
  - 歷史入庫查詢
- **《SCM_退倉申請API》**
  - 歷史退倉查詢
- **《退倉單通知API》**
  - 退倉通知查詢

### 2. 申請使用

- **《申請入庫API》**
  - 可申請入庫查詢
  - 已申請入庫查詢
- **《SCM_退倉申請API》**
  - 查詢可申請良品退倉相關商品
  - 已申請退倉查詢

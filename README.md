# Chengde Admin

An administration application running on
[vinext](https://github.com/cloudflare/vinext).

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

## Included Shape

- edit site code under `app/`
- `vite.config.ts` configures the vinext and Cloudflare Vite plugins

## Useful Commands

- `npm run dev`: start local development
- `npm run build`: build the application
- `npm test`: build and run project tests
